# 安全说明

## API Key

插件使用 API Key 访问 Context Service。应使用最小权限的普通用户 Key，不要使用管理员 Key。

请在本机终端中通过隐藏输入配置 API Key，不要把它粘贴到 Qoder 聊天、命令参数、代码仓库或共享日志中。macOS/Linux 上的配置文件仅允许当前用户读写。如果 Key 泄露，应立即撤销并轮换。

## 网络与身份

非本机服务地址必须使用 HTTPS。Context Service 的接入层负责根据 API Key 确定用户的数据访问范围，插件不会自行指定或扩大访问范围。

服务不可用时，自动上下文能力不会阻断 Qoder。自动注入的内容不能替代权限控制、代码审查或安全策略。

## 对话和工具

对话同步和长期记忆保存默认关闭。开启后只发送当前轮的用户文本和助手文本，不发送完整聊天记录、工具输入输出、工作目录、仓库名或文件内容。

保存记忆、删除记忆和追加事件等写操作不会被安装器预授权。用户应检查 Qoder 的权限确认内容后再决定是否允许。

四个 `/context-*` 命令不会读取或输出配置文件正文，也不会显示 API Key。远端错误只以脱敏分类展示，不输出凭据或远端原始响应内容。

## 安装和升级

正式安装器只接受 HTTPS 发布信息和下载内容，并校验版本、文件大小和完整性。安装、升级与卸载使用当前用户目录，不调用 `sudo`。

升级成功后才切换到新版本；失败时恢复上一可用版本。安装器不会覆盖来源不明的同名插件或工具连接，卸载器也不会删除被用户修改的配置。

彻底清理只作用于已知的 Context Service 配置和状态位置，并要求用户明确确认。

## 漏洞报告

正式发布前需要补充外部安全联系人、支持版本策略、预期响应时间和漏洞披露流程。
