# ADBPG Context Service Plugin

ADBPG Context Service Plugin 是 Context Service 面向智能编码工具的集成插件集合，用于将团队规则、项目知识、长期记忆和会话上下文引入研发过程，帮助模型获得更准确、更连续的上下文。

## 主要能力

- 自动装配与当前用户、团队和项目相关的上下文
- 根据当前问题召回相关知识和长期记忆
- 支持长期记忆的保存、查询、召回和管理
- 支持规则、会话历史和事件信息的按需查询
- 支持对话同步与自动记忆提取
- 服务不可用时安全降级，不影响智能编码工具的基本使用

## 设计原则

- **统一接入**：为不同智能编码工具提供一致的 Context Service 能力。
- **按需启用**：自动召回、对话同步和记忆提取等能力可独立配置。
- **安全可控**：敏感配置保存在用户本机，数据写入与删除遵循客户端权限确认机制。
- **隐私优先**：明确数据处理范围，避免采集与上下文能力无关的信息。

## 当前支持

当前仓库提供 Qoder 插件，支持 Qoder IDE 和 Qoder CLI。具体安装、配置和使用方式请参阅 [Qoder 插件文档](./qoder/README.md)。
